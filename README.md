# Hiyori Portfolio PoC

ChatGPT × GitHub × v0 の開発ワークフローを検証するための公開PoCです。

> [!IMPORTANT]
> **水瀬ひより（Hiyori Minase）と掲載する作品・経歴はすべて架空です。**
> 実在の人物のポートフォリオではありません。

## 目的

単にAIでWebサイトを生成するのではなく、次の開発ループを検証します。

1. **ChatGPT** が仕様・実装方針を定義する。
2. **GitHub** をソースコードと変更履歴の正本にする。
3. **v0** がUIの初期実装と改善を担当する。
4. **GitHubのPR** 上でChatGPTが差分をレビュー・必要な修正を行う。
5. v0側に変更を取り込み、継続開発できるか確かめる。
6. 必要に応じて **Vercel** でプレビュー・公開する。

## サイトの初期スコープ

- レスポンシブなシングルページポートフォリオ
- Hero / About / Skills / Projects / Contact
- 架空の開発実績を3〜4件紹介
- 日本語を主とした内容。英語表記は必要最小限
- シンプルで実務的、余白とタイポグラフィを重視したデザイン
- 実在人物の写真・経歴を流用しない
- ダミーの連絡先・リンクを実在の窓口として表示しない

**予定する技術:** Next.js (App Router), React, TypeScript, Tailwind CSS。
プロフィールの職業はPHPですが、この展示サイト自体のバックエンドにPHPは不要です。

## 検証で観察すること

- GitHub ↔ v0 の変更取り込みとブランチ・PRの扱い
- ChatGPTが加えた変更のv0側への反映
- v0が既存コードを過度に再生成しないか
- ビルドの再現性、レビュー可能な差分、デプロイの整合性

Zenn記事では結果だけでなく、成功・失敗と修正の履歴を記録します。

## セキュリティ・権利

公開リポジトリのため、APIキー、認証情報、個人情報、実在の案件情報を含めません。画像を使う場合は利用許諾が明確なもの、または独自制作のものに限ります。
