# Product brief — Hiyori Portfolio PoC

## 0. 前提

このプロジェクトは、ChatGPT・GitHub・v0・Vercelの連携を検証するための公開デモです。水瀬ひより、および掲載する職務経歴・実績・作品は**完全な架空設定**です。

## 1. ペルソナ

- 名前: 水瀬ひより / Hiyori Minase
- 年齢: 23歳
- 職業: PHP / Laravel中心のWebエンジニア
- 得意: Webアプリケーション開発、API、データベース、レガシー改善
- 技術: PHP 8.x, Laravel, MySQL, Docker, AWS, React / TypeScript
- キャッチコピー: 「古いコードも、新しい技術も。」
- 文体: 若手らしい簡潔さ。過度に誇張したキャリア・資格・大規模案件を捏造しない

## 2. サイト

- 日本語主体のシングルページ
- セクション: Hero, About, Skills, Projects, Contact
- モバイル・デスクトップ双方に対応
- Projectsは架空のデモ案件として明示:
  - **Task Tempo:** Laravelによるタスク管理アプリのデモ
  - **API Sketchbook:** Laravel REST API / OpenAPIの学習・検証用サンプル
  - **Legacy Notes:** PHPレガシーコードのリファクタリングを題材にした技術ノート
- Contactは表示用。送信できるように見せかける未実装フォームを設置しない
- SNS/外部リンクを設置する場合、無効なリンクや実在する第三者のアカウントに誘導しない

## 3. ビジュアル

- IT製品のランディングページより、洗練された個人開発者サイトに寄せる
- ゆとりある余白、明瞭な見出し、適切なコントラスト
- 色: オフホワイト / チャコール / 少量のブルーグリーンを提案
- 若さは情報設計と軽快さで表現し、過度な「かわいい系」は避ける
- 人物写真は必須ではない。本人を装う実在人物の肖像を使わない
- アニメーションは控えめ。reduced-motion設定に配慮

## 4. 技術要件

- Next.js App Router, React, TypeScript, Tailwind CSS
- 静的コンテンツを基本とし、PHPバックエンド・DB・認証は不要
- プロフィール・作品データをUIと分離
- セマンティックHTML、キーボード操作、画像alt、アクセシブルな色
- SEOタイトル・description。デモであることが分かるメタ情報
- 公開時に機密情報や個人情報が漏れない設計
- READMEの既存PoC情報とdocs/を残す

## 5. MVPの受け入れ条件

- `npm install` と `npm run build` が通る
- 幅360px付近からデスクトップまで、文字切れと横スクロールがない
- 主要セクションに到達できる
- Projectsが個別に説明され、架空デモだと分かる
- リンクが意図しない実在サイトへ飛ばない
- 公開時に「架空の人物・実績によるデモ」と明示される

## 6. ワークフロー検証項目

| ID | 検証内容 | 判定方法 |
| --- | --- | --- |
| WF-01 | ChatGPTからGitHubのリポジトリを読める | リポジトリのメタデータを取得 |
| WF-02 | ChatGPTからGitHubにコミットできる | 初期ドキュメントをコミット |
| WF-03 | v0が既存リポジトリを使って実装できる | UI実装をGitHubに反映 |
| WF-04 | ChatGPTがv0の差分をレビューできる | PR diffを読んでレビュー |
| WF-05 | ChatGPT側修正をv0が取り込める | 変更後のUIが一致 |
| WF-06 | Vercelにデプロイできる | Preview/Productionで表示を確認 |

## 7. PoCの範囲外

- 実際の求人応募や個人情報収集
- 本格的なCMS・ユーザー認証・管理画面
- バックエンドAPI / データベース
- 実績の真実性を装う表現
